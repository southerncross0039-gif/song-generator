固定（テンプレート）

  • 曲構成：イントロ4 → A8 → B8 → サビ8 → 間奏4 → A8 → B8 → サビ8 → アウトロ4（60小節）。拡張で「ラスサビ×2」または「Dメロ → 落ちサビ → ラスサビ」をサビ2のあとに追加できる
  • サビ設計：1拍目の長い音でフック → 7小節目で最高音 → 主音へ解決。2回目のサビは同じメロディ
  • Aメロは裏拍、サビは表拍（Max Martin のコントラスト）。Bメロ最後の半拍は全楽器を抜く
  • ドラム：Copeland 基調（ハット／リム主体・キック最小）。サビ前はフィルなしで止める（U2ブレイクを選ぶと、瀬谷スタイルと同じくサビ前・間奏明け・歌い出し前に1小節フィル）
  • ギター：Marr 型のルートレス分散和音＋9th。トップノートは順次進行
  • 展開：イントロはギターのみ → A1は薄く → A2で Strings 追加 → 間奏で Strings がフックを再現 → サビ2で対旋律と Lead → （拡張）Dメロは Strings 主導のハーフタイム、落ちサビはドラムを抜き、ラスサビで全開
