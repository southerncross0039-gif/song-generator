生成結果

• ボーカルは Vocal（リード）・Double・Harmony・VoxLow の4トラックに分けて書き出します。🎤 .svp には同じ4トラックが母音のヴォカリーズ（ah／oh／ooh、メリスマは「-」）で入るので、Synthesizer V でそのまま歌わせ、あとから歌詞に差し替えられます。
• 空間系は MIDI の各トラックに CC91（リバーブ量）・CC93（コーラス量）・CC10（パン）として入れてあります。Logic では各トラックの Send で Space Designer（Hall／Cathedral）と Stereo Delay（1/8 付点）に送るのが目安です（詳しくは「Logic取り込み手順.txt」）。
• ブレイクビーツは AD2 の標準キーマップで書き出します。編集済みのパターンなので、そのまま鳴らすだけで刻み直したブレイクになります。さらに崩すなら Logic の Beat Breaker や Remix FX を Drums に挿してください。
• MP3／WAV 書き出しは ▶ 試聴と同じ簡易シンセの音です（イメージ共有用）。本番は MIDI を Logic の音源で鳴らしてバウンスしてください。凡例で外したパートは書き出しにも入りません。
• 凡例をクリックすると、そのパートを試聴・ピアノロールから外せます。

固定（曲の組み立て方）

  • Melodic Math：サビは2小節の動機 → 反復（模続進行）→ 前半の断片化で上昇 → 主音へ解決。最高音は5〜7小節目。Aメロ（低め）＜ Bメロ（上昇の模続進行）＜ サビ（最高音）の順に高くする
  • 構成（標準・74小節）：イントロ（ブレイク）4 → Aメロ8 → Bメロ4 → サビ8＋8 → 間奏（ブレイク編集・楽器がサビを再現）8 → Aメロ8 → Bメロ4 → ラスサビ8＋8 → アウトロ6
  • セクションのつなぎは短く：Bメロ最後の1拍は全員を止め、サビ頭でクラッシュ（フィルより音量差で見せる）
  • 不協和の除去：強拍と長い音は必ずコード音か半音でぶつからないテンション。伴奏はその間のメロディと半音でぶつかる音を抜く。最後に短2度の衝突率を実測して自動修正
  • ブレイク編集：イントロと間奏で細かく、Aメロは控えめ、サビは4小節ごとのフレーズ終わりにロール
