• Logic への取り込み：書き出した .mid を Finder から Logic のトラックエリアへドラッグ。Drums / Bass / Guitar / Lead / Vocal / Piano / Strings / Edge / Marr / Synth（＋ AD2 書き出しでは Perc）の最大11トラックとセクションマーカーが入ります。音色は GM で指定済み（Drums＝ch10 ドラムキット、Bass＝Finger Bass、Guitar＝Overdriven Guitar、Lead＝Distortion Guitar、Vocal＝Synth Voice、Piano＝Grand Piano、Strings＝String Ensemble、Edge＝Clean Guitar）。読み込み後に Drums を Addictive Drums 2、Vocal を Synthesizer V に差し替えてください。
• Guitar（壁）は1本分のストロークです。Logic でトラックを複製（⌘D）して左右に振り（L-70 / R+70）、片方の Quantize を外すかタイミングを 5〜10ms ずらすとダブルトラックの厚みになります。アンプは Amp Designer の British 系・ゲイン中程度が目安です。
• Marr（Smiths）は1本のクリーンギターで和音を分散させるトラックです。Logic では Clean 系アンプ＋Compressor 強め（Ratio 4:1 前後）＋Chorus 薄め＋短い ChromaVerb が目安です。トップノートだけベロシティを強めに書いてあります。
• Edge（U2）は8分のドライ音です。Logic で Delay Designer か Tape Delay を挿し、Time 1/8 付点・Feedback 35〜45%・Mix 35% 前後にすると The Edge の付点8分になります（試聴では簡易ディレイ済み）。イントロ・Aメロ・Bメロ・サビ1・Dメロで鳴り、間奏とサビ2以降は Noel の Lead に譲ります。
• Lead（Noel）は間奏とアウトロでサビのフックを1オクターブ上で弾き、サビ2以降ではロングトーンの対旋律を弾きます。Pedalboard でファズ＋リバーブを足すと Noel らしくなります。
• Strings には CC11（Expression）でBメロ後半のスウェルとアウトロのフェードを書き込んであります。
• 音節数（ピンク）は歌詞の語数の目安です。1音符＝1音節で書けば、メロディを崩さずに歌詞を載せられます。

固定（テンプレート）

  • 曲構成（既定＝3分半）：イントロ8 → A8 → B8 → サビ8 → 間奏4 → A8 → B8 → サビ8 → ギターソロ8 → Dメロ8 → 落ちサビ8 → ラスサビ8 → ラスサビ×2 8 → アウトロ12（112小節・BPM128 で 3:30）。「曲の長さ」で標準60小節・3分構成などにも切り替えられる
  • サビ設計：1拍目の長い音でフック → 7小節目で最高音 → 主音へ解決。2回目のサビは同じメロディ
  • サビ前は止めずに突っ込む：Bメロ最終小節はタム回し（またはスネア連打のビルドアップ）→ サビ頭でクラッシュ
  • ドラム：8ビート。Aメロはクローズドハット、Bメロはライド＋8分タンバリン、サビはオープンハットと2小節ごとのクラッシュ＋16分タンバリン
  • ギター：開放弦ポジションの6弦ストローク（ダウン／アップの弦ずらし付き）。ドローン弦で全コードに共通音を鳴らし、ぶつかる3度は抜いて sus 化
  • ベース：8分のルート弾き。コードが変わる直前の8分だけ順次で次のルートへ寄る（A1 は4分）
  • Bacharach（Second）スタイル（Second の13進行を選ぶと自動でオン）：Marr の分散和音が主役（歪みギターなし）・Bacharach のピアノ（アンティシペーション）・Jamerson のベース・Copeland のドラム・サビ前の半拍抜き・Bメロ最後の 2/4・Karen Carpenter の女声の音域（SynthV はそのままの高さ）・間奏は Strings がフックを再現・Edge 型のリードは間奏／サビ2以降／Dメロ／アウトロ
  • Melodic Math（Max Martin）（既定オン）：各セクションの最初のフレーズをモチーフにして A A' B A''（4フレーズなら3つ目を2度上げ）で反復、Bメロは1フレーズごとにせり上げ、短い音は順次・跳躍は長い音だけ。歌詞は1行＝1フレーズで同じ長さの行は同じ語数（1音節1音符にぴったり入る行を優先）、サビはタイトルで始めてタイトルで終わる
  • The Smiths 要素（Smiths の曲を選ぶと自動でオン）：Marr の分散和音（3〜4音・トップノートが順次で動く）／Rourke の動くベース／Morrissey 型の歌メロ（A・B・サビに各1型）。このとき歪みギターはサビ・間奏の8分だけに引っ込み、U2 要素とドローンは自動でオフ
  • U2 要素（各オン・オフ可）：サビ前・間奏明け・歌い出し前に U2 ブレイク／Edge の8分アルペジオ／Aメロは Larry の4つ打ち＋16分ハット、Bメロはフロアタム／Aメロは Adam の主音ペダル／サビ前は Beautiful Day の原曲ブレイク（オプションで全編を Beautiful Day のドラムに）
  • Taylor Swift ／ The Weeknd 要素（その曲を選ぶと自動でオン）：Max Martin のポップ・ドラム（Shake It Off のドラムライン／We Are Never Ever のポップロック／Blank Space のハーフタイム＋クリック／Blinding Lights の80s 4つ打ち＋タム回し／Can't Feel My Face のディスコ）・曲ごとのベース（パルス・伸ばし・シンコペーション）・Synth トラック（80s リフ／ホーン・スタブ／プラック）・クラップ 2・4拍・サビ前の無音・ラスサビ前の1小節ブレイク。Weeknd 型は Piano をシンセ・パッドとして全音符で鳴らし、歪みギターと Noel のリードは鳴らさない
