生成結果

• テーマの担当（ピンク）はセクションごとに楽器が替わります（例: Williams はホルン → トランペット → 弦 → 全員）。同じメロディを楽器を替えて何度も聴かせるのが劇伴のテーマの立て方です。
• Logic への取り込み：書き出した .mid を Logic のトラックエリアへドラッグ（または 📦 一括書き出しで自動で開く）。テンポ（リタルダンド込み）とセクションマーカーが入ります。各トラックの音色のおすすめは「Logic取り込み手順.txt」に書き出されます。
• 空間系：劇伴は残響が主役です。Strings／Choir／Theme は Space Designer か ChromaVerb の Hall 系（Decay 2.5〜4s）を Aux に立てて送るのが目安です。Vangelis は 5s 以上の長いホールでも合います。
• 凡例をクリックすると、そのパートを試聴・ピアノロールから外せます。

固定（テーマの作り方）

  • 動機（2小節）：特徴的なリズム＋印象的な跳躍を1つだけ持つ。テーマ・ビルド・コーダはすべてこの動機から作る
  • テーマ（8小節）：文型＝動機 → 動機の反復／模続進行 → 前半の断片化で上昇 → 終止。楽節型＝前楽節（半終止）→ 後楽節（全終止）。最高音は5〜7小節目に置き、主音へ解決
  • テーマ1回目は半終止（開いて終わる）、2回目は全終止（主音で閉じる）。合わせて16小節の大きな問いと答え
  • 和声音の規則：1・3拍目と長い音は必ずコード音（または半音でぶつからないテンション）。非和声音は短い経過音・刺繍音だけ。伴奏に乱数は使わない
  • 構成（標準・54小節）：イントロ（予告）4 → テーマ提示8 → テーマ確保8 → 対照主題8 → ビルド4 → クライマックス8 → クライマックス（終止）8 → コーダ6
  • 展開：段階的に楽器を足して最後に全員でテーマを歌う。クライマックスはテーマを複数の楽器でオクターブ重ね（必要なら転調）
